# Tic-Tac-Toe Web Application 🎮

A responsive Tic-Tac-Toe game built using HTML, CSS, and JavaScript as part of the Prodigy Infotech Web Development Internship.

## Features

- Two Player Gameplay
- Win Detection Logic
- Draw Detection
- Restart Game Button
- Responsive Design
- Interactive User Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

PRODIGY_WD_03

1. Download or clone the repository
2. Open the folder in VS Code
3. Open index.html
4. Run using Live Server
